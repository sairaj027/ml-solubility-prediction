# 🧠 My First Machine Learning Project

## 📌 Overview

This project demonstrates the implementation of Machine Learning regression models using Python and Scikit-learn.

The notebook includes:

- Data Loading
- Data Preprocessing
- Feature Selection
- Train-Test Split
- Linear Regression
- Random Forest Regression
- Model Evaluation
- Performance Comparison

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

---

## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/sairaj027/first-project-ml.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Jupyter Notebook

```bash
jupyter notebook
```

Open

```
first_project_ML.ipynb
```
